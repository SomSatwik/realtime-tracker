# Contributing

Thanks for your interest in improving Real-Time Tracker — contributions are welcome.

Quick guidelines
- Fork the repository and create a feature branch (feature/my-change).
- Keep changes small and focused. Open an issue for larger features before implementing.
- Follow existing code style and add comments where helpful.
- Add tests for bug fixes or new features when practical.

Pull request checklist
- [ ] Code builds locally and lints (if applicable)
- [ ] Relevant tests added or updated
- [ ] README updated when introducing new features or breaking changes
- [ ] Provide a clear description of the change and why it’s needed

Reporting bugs
- Open an issue with reproduction steps, expected vs actual behavior, and environment details (OS, Node version).
